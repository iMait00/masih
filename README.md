# ماسح 
برنامج يهدف لإستعادة الوثائق العربية القديمة وتحويلها إلى مستندات حديثة قابلة للنسخ.
pdf - word - docs - md

## ميزة التدقيق القرآني
يحتوي البرنامج على نسخة مدمجة من القرآن بالرسم العثماني للتحقق من صحة الآيات المقتبسة. لا يتم إجراء أي تغيير تلقائي بل تُعرض التصحيحات كلمة بكلمة لتراجعها وتعتمدها بنفسك.

## المسح الضوئي
يحتاج إنترنت ومفتاح API من [Mistral](https://console.mistral.ai) او أي أداة OCR



### تنبيه: الأداة للمساعدة فقط ويجب مراجعة التصحيحات يدوياً قبل اعتمادها.
